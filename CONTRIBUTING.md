# Contributing

Thank you for improving em-verse.

1. Create a focused branch from the latest `main`.
2. Install dependencies with `corepack enable` and `yarn install --frozen-lockfile`.
3. Keep credentials and personal data out of code, tests, logs, screenshots, and fixtures.
4. Add or update tests for behavior changes.
5. Run `yarn test`, `yarn build`, and `yarn audit` before opening a pull request.
6. Explain the motivation and user impact in the pull request description.

Security reports belong in the private process described in [SECURITY.md](SECURITY.md), not in public issues or pull requests.
